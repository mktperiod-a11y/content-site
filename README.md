# 어디서 보지? (working title)

보고 싶은 작품을 검색해 국내 OTT 구독·대여·구매 제공처를 확인하고,
구독형 OTT에서 확인되지 않는 작품은 사용자가 직접 눌렀을 때만 KDisk 이용 방법을
안내하는 검색형 서비스입니다.

## 현재 구현 범위

- 검색 중심 메인 화면 / 가격 비교 계산기 (두 개 탭)
- **실제 KOBIS(영화진흥위원회) Open API 연동 검색**
  - 제목 일부, 감독명으로 검색
  - 자동완성(디바운스), 검색 결과 목록, 결과 없음/로딩/오류 상태
  - 검색 결과 → 작품 상세 페이지 이동
- 작품 상세 페이지 (`/movie/[movieCd]`, KOBIS 실데이터: 감독·출연·국가·장르·상영시간·관람등급)
  - 서버 렌더링, `generateMetadata`, `Movie` 구조화 데이터(JSON-LD)
- 구독형 OTT 제공처 확인 영역과, 확인되지 않는 작품에 대한 2뎁스 KDisk 안내
  - 1뎁스: "다른 이용 방법 확인하기" 버튼을 직접 눌러야 KDisk가 언급됨
  - 2뎁스: "작품 확인하기" → 검색어 복사 → KDisk 신규 가입 화면 이동
  - 이용 가능 여부를 단정하는 문구는 사용하지 않음
- 최대 5편 가격 비교 계산기 (검색/선택/추천/최소비용 조합)
- 작품 상세에서 "가격 비교에 담기" 딥링크 (`/?tab=compare&add=<id>`)
- 반응형 UI, 다크 네이비·시네마틱 옐로 디자인 시스템

## 아직 예시(하드코딩) 데이터인 부분

- **구독형 OTT 제공처·가격 정보**: `lib/movies.ts`의 소수 작품에 한해 예시로 매핑되어
  있습니다. 실제 OTT 제공 현황과 다를 수 있으며, TMDB 또는 적법한 제공처 API 연동이
  필요합니다.
- 포스터, 배경 이미지, TMDB 평점, 리뷰, 줄거리: 아직 없음 (TMDB/KMDb 미연동)
- 가격 비교 계산기의 영화 목록: `lib/movies.ts` 예시 데이터 (KOBIS 실검색과 별개)

KOBIS와 로컬 예시 제공처 데이터는 **작품명 + 제작연도가 정확히 일치할 때만** 연결하며,
불확실한 매칭에는 OTT 정보를 임의로 연결하지 않습니다.

## 환경변수

```bash
cp .env.example .env.local
# .env.local에 KOBIS_API_KEY 값을 채워주세요.
```

`KOBIS_API_KEY`는 서버 전용 코드(`lib/kobis.ts`, `app/api/movies/search`)에서만
사용되며 클라이언트 번들에 포함되지 않습니다. 이 값을 코드나 커밋에 직접 작성하지
마세요.

> 참고: 이 저장소를 다루는 일부 개발 샌드박스는 outbound 네트워크 정책상
> `kobis.or.kr` 접근이 차단될 수 있습니다. 이 경우 검색/상세 페이지는 정상적으로
> "API 오류" 상태를 보여줍니다 (오류 처리 자체는 의도된 동작입니다). 실제 KOBIS
> 응답은 네트워크 제약이 없는 환경(배포 환경, 또는 로컬 PC)에서 확인해주세요.

## 다음 구현 우선순위

1. TMDB 연동: 포스터·배경 이미지·평점·평가 수·줄거리·리뷰, 해외/대체 제목
2. KMDb 연동: 고전 한국영화·KOBIS 누락 보완
3. 국내 OTT 제공처(구독·대여·구매) 실데이터 연동 — 가격 비교 계산기 실데이터화
4. KDisk·OnDisk 내부 콘텐츠 목록과의 매칭
5. 신규·변경 작품 자동 갱신 배치
6. sitemap, canonical URL(프로덕션 도메인 확정 후), 검색결과 페이지 색인 정책
7. GA4 전환 퍼널 연결 (현재는 주요 액션에 `data-ga-event` 속성만 부여된 상태이며,
   실제 GA4 전송 연동은 별도 작업이 필요합니다)
