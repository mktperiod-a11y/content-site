# 어디서 보지? (working title)

보고 싶은 작품을 검색해 국내 OTT 구독·대여·구매 제공처를 확인하고,
구독형 OTT에서 확인되지 않는 작품은 사용자가 직접 눌렀을 때만 KDisk 이용 방법을
안내하는 검색형 서비스입니다.

## 현재 구현 범위

- 검색 중심 메인 화면 / 가격 비교 계산기 (두 개 탭)
- **실제 KOBIS(영화진흥위원회) Open API 연동 검색**
  - 제목 일부, 감독명으로 검색
  - 자동완성(디바운스), 검색 결과 목록, 결과 없음/로딩/오류 상태
  - 검색 결과 → 작품 상세 페이지 이동
- 작품 상세 페이지 (`/movie/[movieCd]`)
  - KOBIS 실데이터: 감독·출연·국가·장르·상영시간·관람등급
  - **TMDB 실연동**: 포스터·배경 이미지·줄거리·평점(평가 수 포함)·사용자 리뷰
  - **국내(KR) OTT 제공처 실데이터**: 구독·대여·구매 구분 (TMDB watch/providers)
  - 평가 수가 적으면(50명 미만) 평점을 강조하지 않고 "참고용"으로 표기
  - 리뷰가 없으면 가짜 리뷰 대신 "등록된 리뷰 없음" 상태 표시
  - TMDB·JustWatch 출처 표기
  - 서버 렌더링, `generateMetadata`, `Movie` 구조화 데이터(JSON-LD)
- 구독형 OTT 제공처 확인 영역과, 확인되지 않는 작품에 대한 2뎁스 KDisk 안내
  - 1뎁스: "다른 이용 방법 확인하기" 버튼을 직접 눌러야 KDisk가 언급됨
  - 2뎁스: "작품 확인하기" → 검색어 복사 → KDisk 신규 가입 화면 이동
  - 이용 가능 여부를 단정하는 문구는 사용하지 않음
- 최대 5편 가격 비교 계산기 (검색/선택/추천/최소비용 조합)
- 작품 상세에서 "가격 비교에 담기" 딥링크 (`/?tab=compare&add=<id>`)
- 반응형 UI, 다크 네이비·시네마틱 옐로 디자인 시스템

## 아직 예시(하드코딩) 데이터인 부분

- **가격 비교 계산기(2탭)**: 영화 목록과 OTT 월요금이 모두 `lib/movies.ts` 예시
  데이터입니다. TMDB는 제공처는 알려주지만 요금제 가격은 제공하지 않으므로, 실제
  요금 데이터는 별도로 확보해야 합니다. 화면에 "예시" 배지로 표기 중입니다.
- KMDb 연동(고전 한국영화·KOBIS 누락 보완)은 아직 없습니다.

작품 상세의 제공처 정보는 TMDB 실데이터입니다. KOBIS 작품을 TMDB에 매칭할 때는
**제목(한국어/원제/영문)이 정규화 후 정확히 일치하고 개봉연도가 ±1년 이내인 경우에만**
연결하며, 불확실한 매칭에는 정보를 임의로 연결하지 않습니다. 매칭에 실패하면 제공처를
단정하지 않고 "확인하지 못했어요" 상태를 보여줍니다.

## 환경변수

```bash
cp .env.example .env.local
# .env.local에 KOBIS_API_KEY, TMDB_API_KEY 값을 채워주세요.
```

두 키 모두 서버 전용 코드(`lib/kobis.ts`, `lib/tmdb.ts`, `app/api/movies/search`)에서만
사용되며 클라이언트 번들에 포함되지 않습니다. 이 값을 코드나 커밋에 직접 작성하지
마세요. Cloudflare Workers로 배포할 때는 `.env.local`이 함께 올라가지 않으므로
`wrangler secret put`으로 별도 등록이 필요합니다.

> **개발 샌드박스 주의**: 일부 개발 환경은 outbound 네트워크 정책상 `kobis.or.kr`,
> `api.themoviedb.org` 접근이 차단됩니다. 이 경우 검색/상세 페이지는 의도대로 "API 오류"
> 상태를 보여줍니다. 네트워크 없이 화면을 검증하려면 `KOBIS_API_BASE`,
> `TMDB_API_BASE`, `TMDB_IMAGE_BASE`를 로컬 목 서버로 지정하세요.

## 다음 구현 우선순위

1. 가격 비교 계산기 실데이터화 — OTT 요금제 가격 확보 (TMDB는 제공처만 알려주고
   가격은 제공하지 않음)
2. KMDb 연동: 고전 한국영화·KOBIS 누락 보완
3. KDisk·OnDisk 내부 콘텐츠 목록과의 매칭
4. 신규·변경 작품 자동 갱신 배치
5. sitemap, canonical URL(프로덕션 도메인 확정 후), 검색결과 페이지 색인 정책
6. GA4 전환 퍼널 연결 (현재는 주요 액션에 `data-ga-event` 속성만 부여된 상태이며,
   실제 GA4 전송 연동은 별도 작업이 필요합니다)
