# 극장 상영 정보 조사 (2026-09-10)

CGV·메가박스·롯데시네마의 "현재 상영작" 데이터를 실제로 호출해 확인한 결과입니다.
브라우저에서 각 사이트를 열어 네트워크 요청을 추적하고, 응답을 직접 받아 필드를 확인했습니다.

> ⚠️ 세 곳 모두 **공식 공개 API가 아니라 각 사이트가 자기 화면을 그릴 때 쓰는 내부 엔드포인트**입니다.
> 예고 없이 바뀔 수 있으므로, 실패했을 때 화면이 깨지지 않도록 설계해야 합니다(아래 "실패 처리" 참고).

## 1. 엔드포인트

### CGV — 현재상영작 61편

```
GET https://api.cgv.co.kr/met/dsp/scrDsp/searchScrDspCpotDtl?coCd=A420&unitCpotRelNo=1
```

- 인증·헤더 불필요. 응답 약 180KB JSON.
- 응답 안에 탭 6개가 한꺼번에 들어 있습니다:
  `무비차트(99)` / `현재상영작(61)` / `상영예정(67)` / `ICECON(11)` / `아트하우스(26)` / `CGV Only(7)`
- 경로: `data` → (중첩) → `tabExpoNm`으로 탭 구분 → `movctSearchResDtoList`가 영화 배열

**영화 객체 주요 필드**

| 필드 | 의미 | 예시 |
|---|---|---|
| `movNo` | CGV 영화 코드 | `30001323` |
| `movNm` | 제목 | `스파이더맨-브랜드 뉴 데이` |
| `realOpenYmd` / `rlsYmd` | 개봉일 | `20260805` |
| `rrlsYn` | **재개봉 여부** | `Y` / `N` / 공백 |
| `atktPsblYn` | 예매 가능 | `Y` |
| `atktRate` | 예매율 | `49.94` |
| `accAdncCnt` | 누적 관객 | `10268421` |
| `egix` | 에그지수 | `98` |
| `genr` | 장르 | `액션, 드라마, 어드벤처` |
| `cratgClsCd` | 관람등급 코드 | `02` |
| `imgPath` + `img320Fnm` | 포스터 경로 | |

### 메가박스 — 상영중 75편

```
POST https://www.megabox.co.kr/on/oh/oha/Movie/selectMovieList.do
Content-Type: application/json;charset=UTF-8

{"currentPage":"1","recordCountPerPage":"200","pageType":"ticketing",
 "ibxMovieNo":"","onairYn":"Y","specialType":"","isAdult":"",
 "masterType":"movie","sortType":"1"}
```

- `onairYn: "Y"` 가 상영중 필터입니다. 응답 `movieList` 배열, `totCnt`에 총 개수.

**영화 객체 주요 필드**

| 필드 | 의미 |
|---|---|
| `movieNo` | 메가박스 영화 코드 |
| `movieNm` | 제목 |
| `rfilmDe` / `rfilmDeReal` | 개봉일 |
| `movieStatCd` / `movieStatNm` | 상영 상태 (`MSC01` = 상영중) |
| `bokdAbleYn` / `bokdAbleAt` | 예매 가능 |
| `boxoRank` / `boxoKofTotAdncCnt` | 박스오피스 순위·누적관객 |
| `admisClassNm` | 관람등급 |
| `playTime` | 상영시간 |
| `mxTheabAt` `dbcTheabAt` `mx4dTheabAt` `boutqTheabAt` `megaCubeAt` | 특별관 여부 (MX/돌비/4D/보떼끄/메가큐브) |
| `filmAt` / `classicAt` | 필름소사이어티 / 클래식소사이어티 |

> ⚠️ 조회된 75편이 **전부 `MSC01(상영중)`** 으로 나옵니다. 개봉 예정작(예: `인턴`, 개봉일 2026-09-16)도
> 섞여 있으므로 **`movieStatCd`만 믿지 말고 `rfilmDe`(개봉일)를 함께 봐야 합니다.**

### 롯데시네마 — 현재상영작 47편

```
POST https://www.lottecinema.co.kr/LCWS/Movie/MovieData.aspx
Content-Type: multipart/form-data

paramList={"MethodName":"GetMoviesToBe","channelType":"HO","osType":"Chrome",
           "osVersion":"<UA>","multiLanguageID":"KR","division":1,
           "moviePlayYN":"Y","orderType":"1","blockSize":1000,
           "pageNo":1,"memberOnNo":"0","imgdivcd":2}
```

- `paramList`는 **폼 필드**로 보냅니다(JSON 본문 아님). 파라미터가 하나라도 빠지면
  `{"IsOK":"false","ResultMessage":"호출 파라미터가 부족합니다."}` 를 반환합니다.
- `moviePlayYN`: `Y` = 현재상영작, `N` = 개봉예정작
- 응답 경로: `Movies.Items` (배열), `Movies.ItemCount`

**영화 객체 주요 필드**

| 필드 | 의미 |
|---|---|
| `RepresentationMovieCode` | 롯데 영화 코드 |
| `MovieNameKR` / `MovieNameUS` | 제목(한/영) |
| `ReleaseDate` | 개봉일 (`2026-08-05 오전 12:00:00` 형식) |
| `MoviePlayYN` / `MoviePlayEndYN` | 상영중 / 상영종료 |
| `BookingYN` / `BookingRate` / `BookingRank` | 예매 가능·예매율·순위 |
| `SoloOpenYN` | 단독 개봉 여부 |
| `OpenORClosing` | 개봉/종영 구분 |
| `SpecialScreenDivisionCode` | 특별관 구분 |
| `DirectorName` / `ActorName` / `MovieGenreNameKR` | 감독·배우·장르 |
| `ViewGradeNameKR` | 관람등급 |

> ⚠️ **응답에 광고가 영화처럼 섞여 들어옵니다.** `MovieNameKR: "AD"`, `ReleaseDate: null` 인
> 항목이 실제로 존재합니다. `ReleaseDate`가 없거나 코드가 비어 있는 항목은 걸러내야 합니다.

## 2. 제목 표기 — 매칭의 핵심

**같은 영화를 세 곳이 다르게 적습니다.** 특히 CGV가 특이합니다.

| 영화 | CGV | 메가박스 | 롯데시네마 |
|---|---|---|---|
| 스파이더맨 | `스파이더맨-브랜드 뉴 데이` | `스파이더맨: 브랜드 뉴 데이` | `스파이더맨: 브랜드 뉴 데이` |
| 연옥 | `연옥-살인마들의 자치구역` | `연옥: 살인마들의 자치구역` | `연옥: 살인마들의 자치구역` |
| 명탐정 코난 | `명탐정 코난-하이웨이의 타천사` | `명탐정 코난: 하이웨이의 타천사` | `명탐정 코난: 하이웨이의 타천사` |
| 하츄핑 | `사랑의 하츄핑-고래보석의 전설` | `사랑의 하츄핑: 고래보석의 전설` | `사랑의 하츄핑: 고래보석의 전설` |

### 정규화 규칙

1. **CGV는 콜론 `:` 을 하이픈 `-` 으로 바꿔 표기합니다.** 메가박스·롯데는 콜론 그대로.
   → 매칭 전에 `:` 와 `-` 를 같은 구분자로 취급해야 합니다.
2. **하이픈 주변 공백이 제각각입니다.** `아이유 콘서트 - 더 골든 아워`, `파뿌리 24- 좀비 아일랜드`
   → 구분자 주변 공백 제거.
3. **띄어쓰기가 다릅니다.** CGV `리틀 드래곤-몬스터섬의 비밀` vs KOBIS `리틀 드래곤: 몬스터 섬의 비밀`
   → **공백을 전부 제거한 문자열로 비교**하는 게 가장 안전합니다.
4. **물음표 등 문장부호 차이.** 롯데 `어떻게 해야 했을까?` vs CGV `어떻게 해야 했을까`
   → 끝의 문장부호 제거.
5. **특별관 표기는 제목에 안 붙습니다.** 세 곳 모두 별도 필드로 관리합니다(4DX, MX, 돌비 등).
   → 걱정했던 `(4DX)` `(자막)` 문제는 **없습니다.**

**권장 정규화**: `제목 → 공백 전부 제거 → : - ~ 등 구분자 통일 → 끝 문장부호 제거 → 소문자화`

## 3. 재개봉 처리 — 극장사마다 다릅니다 ⚠️

같은 재개봉작을 세 곳이 서로 다르게 기록합니다.

| | CGV | 롯데시네마 |
|---|---|---|
| 개봉일 | **원래 개봉일** (`델마` → `20180815`) | **재개봉일** (`델마` → `2026-xx-xx`) |
| 재개봉 표시 | `rrlsYn = Y` 필드 | 별도 플래그 없음 |

**그래서 개봉일로 KOBIS와 매칭하면 실패합니다.** 반드시 **제목 기준 매칭**을 쓰고,
개봉일은 동명이인 구분용 보조 수단으로만 쓰세요.

CGV `rrlsYn` 값은 `Y` / `N` / 공백 세 가지인데, `파묘`(2024)·`퇴마록`(2025)처럼
명백한 재개봉인데 `N`인 경우가 있어 **입력 편차가 있습니다.** 이 필드를 단독 판정 근거로 쓰지 마세요.

## 4. "최근 60일 개봉작" 필터는 쓰면 안 됩니다 (실증)

CGV 현재상영작 61편 중 **재개봉작이 다수** 확인됐습니다:

`마루 밑 아리에티`(2010) · `모모와 다락방의 수상한 요괴들`(2012) · `파라노만`(2013) ·
`핵소 고지`(2017) · `곤지암`(2018) · `델마`(2018) · `스파이의 아내`(2021) ·
`파묘`(2024) · `퇴마록`(2025) · `담요를 입은 사람`(2024) · `아이유 콘서트`(2023)

**최근 60일 개봉작으로 후보를 좁히면 이 작품들이 전부 누락됩니다.**
→ 극장사 목록을 기준(정답지)으로 삼고, 거기에 KOBIS 작품 정보를 붙이는 방향이 맞습니다.

같은 날 같은 시각에 조회한 결과입니다.

| | 편수 |
|---|---|

| 메가박스 상영중 | 75 |
| 롯데시네마 현재상영작 | 47 |

**CGV에만 있는 예**: 마루 밑 아리에티, 핵소 고지, 곤지암, 파묘, 퇴마록, 파라노만,
신극장판 은혼, 이누야샤 극장판, 딥 워터, 살목지, 터치드 콘서트, 스파이에어

**롯데에만 있는 예**: 수련, 고스트밴드, 극장판 도라에몽, 길 위의 뭉치, 도그 스타,
빈집의 연인들, 지난 여름, 투모로우바이투게더 VR 콘서트

→ 세 목록을 합치지 말고 **극장사별로 따로 저장**하면 "어디서 상영하는가"가 자동으로 나옵니다.
별도 판별 로직이 필요 없습니다.

## 7. 갱신 주기 — 주 1회로는 부족합니다 ⚠️

국내 극장 상영작은 **매주 수·목요일에 대거 교체**됩니다.
현재 개봉작 카탈로그는 주 1회 갱신인데, 상영 정보를 같은 주기로 돌리면
**최대 6일 동안 이미 내린 영화에 "상영 중" 딱지가 붙습니다.**

→ 상영 정보만 **하루 1회**로 분리 권장. 목록 3개만 받아오는 것이라 부하도 작습니다.

## 8. 실패 처리 — 반드시 3단계로

이 프로젝트가 OTT 제공처에서 이미 쓰고 있는 원칙과 동일하게 가야 합니다
(`제공처 확인 필요` vs `구독형 OTT에서 확인되지 않음` 구분).

| 상황 | 표시 |
|---|---|
| 해당 극장사 목록에서 확인됨 | 예매 버튼 활성 |
| 목록에 없음 | 버튼 비활성 / 흐리게 |
| **수집 자체가 실패** | 기존처럼 3개 다 그대로 표시 (단정하지 않음) |

세 번째를 빼먹으면 크롤링이 하루 깨졌을 때 **상영 중인 영화가 전부 "상영 안 함"으로 뒤집힙니다.**
수집 실패는 극장사별로 따로 기록해서, 한 곳이 실패해도 나머지 두 곳은 정상 반영되게 하세요.

## 9. 남은 확인 사항

- 각 사이트의 이용약관·`robots.txt` 확인 (자동 수집 허용 범위)
- Cloudflare Worker에서 호출할 때 IP 차단 여부 — 하루 1회·3회 호출이면 위험은 낮지만 실제 확인 필요
- CGV `unitCpotRelNo=1` 이 홈 화면 전시 구성에 묶인 값이라, CGV가 홈 개편을 하면 바뀔 수 있음
  (구성 목록은 `searchScrDspCpotList?coCd=A420&screnDispNo=167` 에서 조회 가능)
- 예매 링크는 극장 홈으로 보내기로 확정됐지만, 세 곳 모두 영화 코드를 제공하므로
  나중에 작품별 딥링크로 확장 가능
