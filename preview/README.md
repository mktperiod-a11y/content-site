# 무비시소 미리보기

실제 앱을 그대로 렌더링해 저장한 정적 스냅샷입니다. 작업 중인 화면을
브라우저에서 바로 확인하는 용도이며, 서버·데이터베이스 없이 동작합니다.

- 첫 화면: `index.html` (앱의 1탭 "개봉작"과 동일)
- 상단 탭과 카드 링크로 다른 화면으로 이동할 수 있습니다.

## 한계

스크립트를 제거한 스냅샷이라 다음은 동작하지 않습니다.

- 검색 입력, 탭 전환 등 자바스크립트가 필요한 동작
- 포스터·제공처 로고는 예시 자리표시자입니다. (TMDB 원본 이미지는 포함하지 않습니다)
- 작품 정보는 미리보기용 예시 데이터입니다.
